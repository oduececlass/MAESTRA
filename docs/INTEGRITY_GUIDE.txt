Reducing AI-copying and unauthorized reuse
===========================================

The Student Edition blocks clipboard paste and external drag/drop inside
EE Canvas. This helps prevent a student from directly pasting AI-generated
text, equations, or screenshots into the canvas. It does not make a local
HTML assessment tamper-proof.

Recommended assessment design
-----------------------------
1. Randomize numerical values, device parameters, question order, and diagram
   labels so each student receives a meaningfully different problem.
2. Grade the process: governing equations, assumptions, intermediate steps,
   units, annotations, and consistency checks—not only the final answer.
3. Require a short explanation tied to the student's own diagram, including
   why each band bends, arrow points, or boundary condition is used.
4. Use brief oral or video spot-checks for a sample of submissions. Ask the
   student to explain one step chosen at random.
5. Include error-analysis questions: identify and repair a plausible wrong AI
   solution. This measures understanding rather than answer reproduction.
6. Use time windows appropriate to the task and release questions in smaller
   groups rather than posting the entire assessment far in advance.
7. Compare unusual identical phrasing, diagrams, numerical mistakes, and object
   placement across submissions, while allowing for legitimate collaboration
   and accessibility accommodations.
8. Preserve revision evidence where institutionally permitted: timestamps,
   object counts, and blocked-paste attempt counts. Do not collect clipboard
   contents or unrelated browsing data.
9. For high-stakes exams, use an institution-approved secure browser, testing
   center, identity verification, or proctoring workflow. Review accessibility,
   privacy, and due-process requirements before deployment.
10. State the AI policy clearly: permitted tools, prohibited uses, citation
    expectations, and consequences. Provide a way for students to disclose
    authorized AI assistance.

Limitations
-----------
Client-side restrictions can be bypassed by editing the HTML, using developer
tools, retyping content, using a second device, or uploading a prepared file.
No single technical control can establish authorship. Combine deterrence,
assessment design, transparent policy, and human review.

Student tools correction — v7.1.1
----------------------------------
The Student Edition now uses a narrow paste-only restriction. It does not
intercept drag, drop, pointer, click, selection, drawing, file import, text,
equation, image, or toolbar events. All EE Canvas tools should operate exactly
as in the Teacher Edition except clipboard paste and paste shortcuts.

Students may still use assignment-authorized file import and image tools. For
high-stakes assessments, instructors should disable or avoid such fields in the
quiz design when external prepared files are not permitted.
